# Holiday Home Booking — Vercel-ready

This project is a minimal Next.js booking system with Supabase backend.

## Quick Deploy (No Downloads Required)

### 1. Create Supabase Project
1. Go to https://supabase.com and create a free account.
2. Create a new project.
3. Open the SQL editor and paste `supabase.sql` to create the bookings table and RPC.

### 2. Copy API Keys
- Go to **Settings → API** in Supabase.
- Copy your **Project URL** and **Anon Key**.
- Copy your **Service Role Key** (keep it secret).
